The four panel SVG files are code-native viewport wrappers around the unmodified PNG. They crop the Source, Console, Environment, and Files/Plots/Packages/Help regions without redrawing or changing the interface. `rstudio-overview.svg` adds four course-coloured numbered markers to the unchanged screenshot. Each SVG embeds the exact PNG bytes as a data URI so the image remains self-contained in HTML preview and release bundles; this packaging change does not alter the screenshot. These derived files were created for *Biostatistika a plánování ekologických pokusů (MB120P163)* by Ondřej Mottl and contributors in 2026 and are released under the same CC BY-SA 4.0 terms as the screenshot.
