# RStudio screenshot assets

The RStudio interface assets in this folder are presentation-local raster exports from the approved files under `Learning_materials/figures/`. The PNG format keeps the screenshot visible when RevealJS embeds each asset into a standalone HTML file.

- `rstudio-fresh-install.png` is an unmodified copy of [RStudio - Fresh Install.png](https://commons.wikimedia.org/wiki/File:RStudio_-_Fresh_Install.png), created by Wikimedia Commons user Rcragun on 11 August 2026 and licensed under [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/).
- `rstudio-source.png`, `rstudio-console.png`, `rstudio-environment.png`, and `rstudio-tabs.png` are viewport crops of that screenshot.
- `rstudio-overview.png` adds four numbered markers to the same screenshot.

The crops and numbered overview do not redraw the depicted interface. These derived files are distributed under CC BY-SA 4.0. The unmodified source PNG is stored beside them for provenance and future recropping.
